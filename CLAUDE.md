# Cyberpunk RED DLC

DLC content for the Cyberpunk RED system (`fvtt-cyberpunk-red-core`). The same
contributor and LLM conventions as the core system apply here.

Those conventions — the rules, the full `STYLE_GUIDE.md`, and the entire
mechanics catalog — are vendored from the
[`cpr-llm-rules`](https://gitlab.com/cyberpunk-red-team/cpr-llm-rules) repository
into `.cprc-shared/` via `git subtree`. **Edit them there, not here**; update the
local copy with `git subtree pull --prefix=.cprc-shared <cpr-llm-rules> main --squash`.
